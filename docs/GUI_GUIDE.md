# 首个本地 GUI 使用指南

本轮已获批准的实现是 Home → Stock Explorer → Research。视觉沿用统一报告标准。
这是本地研究工具；真实 PIT/OOS、任意真实池自动回测、真实交易仍未支持。

## 启动与第一个研究

1. Windows 首次双击仓库根目录 `Setup GUI.cmd`（需要已有 Python 3.12 和 uv 0.13.6）。
   uv 可在 PATH 上，或由 `py -3.12 -m uv` 调用；不要求本机开发目录中的工具副本。
   本机依赖已安装，可直接双击 `Start GUI.cmd`，浏览器打开本机地址。
   启动失败会保留提示；只允许一个服务使用 8501 端口。关闭启动器即停止服务。
2. 侧栏默认位置 `work/gui-desk`；首次点“创建工作区”，以后点“打开工作区”。
   可选择自己的本地目录；创建不会覆盖已有目录。工作区中的 TOML/JSON 由程序维护，
   首个研究不要求编辑它们。
3. 到 Stock Explorer，保留 `synthetic 合成样例` 和 `SYN_FACTOR`。
   表格确认 US / XNAS / SYN_FACTOR / USD，勾选身份确认，保存列表。
   自选列表是有版本的静态池，重复保存相同内容复用原版本。
4. 行情来源保留 `synthetic`，默认日期覆盖已打包样例；点击“获取行情”。
   页面展示实际质量、价格曲线、来源和观察/可得时间。内置样例只能获取 SYN_FACTOR，
   不能将 AAPL 等真实证券伪装为合成行情。
5. 点击“加入因子研究”，或从 Research 选择已保存的准确证券/快照。
   默认同时在共同样本比较 FF3/FF4。点击“检查输入”查看共同样本、范围和警告，
   再点击“运行因子研究”。检查会调用真实后端试算，不保存研究报告。
6. Overview 读 Alpha、Beta、R² 与共同观察数；Details 查看系数、区间、滚动失败与诊断；
   Methodology 查看来源、时钟和限制，下载完整报告 ZIP。
   解压后打开 `report.html`；A4、纵向、100%、开启背景图形打印或保存 PDF。
7. 重复提交同一任务复用已有结果；改变参数需点“新实验 / 重试”，并重新检查输入。
   单纯修改控件不会重跑研究。退出/重启后，在同一工作区重新打开已保存任务。
   中断目录和损坏文件会显示错误，不能标为完整结果；原目录保留供诊断。

## 自选股、真实数据与其他页面

- 代码支持粘贴多行/逗号分隔，或导入 CSV。必须逐行确认 market、交易所 MIC、symbol、currency；
  初始 XNAS 是可编辑默认值，不是证券身份认证。不会猜公司名称。错误行和重复项可见。
- `local` 行情选择工作区内现有原生 CSV（需要对应 `.metadata.json` 来源文件）或 Parquet。
  文件契约沿用已验证数据后端。不要求用户编辑 JSON；不能丢弃来源后用普通 OHLC 表替代。
- `yfinance` 仅真实 US/USD，自行明确勾选本次联网后才请求供应商；默认只用缓存。
  “强制刷新”需新任务，产生新快照；缓存过期必须明确允许并显示警告。
  供应商身份/网络失败原样呈现，无合成数据回退。本轮没有执行真实网络行情验收。
- 真实 Factor 使用已有本地 French 格式 FF3、Momentum 文件；月频必须提供现有会话日期文件。
  GUI 不负责认证历史版本和发布时间。真实研究只允许描述性归因。
- Home 的合成示例调用已有完整离线演示，固定 3,000 CAD，创建新目录/账户。
  示例内部脚本审核只适用于明确 synthetic 账户，不会操作用户的现有账户。
  CAD 结果与独立 USD 回测分开；报告 ZIP 保留完整原始文件。
- Paper 页面只读现有工作区内 `.sqlite3` 账户，重读账本摘要；没有写入按钮。
  估值时钟始终显示，经济状态变化后显示过期提示。历史 NAV 不代表当前市场。
- 六页导航保留已批准布局；ML/Backtest 页面说明首版范围，没有未实现的运行按钮。
  Reports 仅发现本 GUI 的任务；旧 CLI/工作流报告仍按原入口打开，未建立全库迁移索引。

## 运行与实现边界

服务仅监听 `127.0.0.1:8501`，无登录、云部署或多用户隔离。请在自己可信的本机使用。
界面中的日期为数据会话日期，所有显示时钟标 UTC。报告生成时间不等于行情/样本时间。
Streamlit 常见操作使用表单；后台任务、取消、自动刷新和一键后台 PDF 没有实现。

`gui/tasks/<command-id>/request.json` 先写，`result.json` 最后写并记录全部文件哈希。
任务目录排他创建，重复 ID 校验输入与结果；不同标签页的不同 ID 可创建独立研究，
不共享审核或账本写连接。失败目录不自动修复。此机制不替代未来 Paper 写入的原子版本校验。
工作区切换清空会话草稿、快照引用与检查状态；完成结果始终从磁盘重读。

可选 `gui` extra 不影响基础 CLI 安装。开发验证需安装 `data/factors/ml/gui` extras。
AppTest 在 Windows 使用 asyncio socketpair，仅该测试组通过 pytest_socket 允许 loopback，
外部数据网络不允许；其他测试仍禁用 sockets。真实浏览器检查与 AppTest 分开记录。
